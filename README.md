# PSInternship
Практическая работа по Git в рамках стажировки в PerfectSystems.
## Описание выполненной работы !
В данном проекте я отработал базовый процесс работы с Git, создание веток, фиксацию изменений и слияние веток с разрешением конфликтов.
1. **Инициализация проекта:**
    Создал локальный проект и инициализировал в нем Git-репозиторий (`git init`).
    Создал стартовый файл `README.md` и сделал первый коммит в ветку `main`.
2. **Работа с фича-ветками:**
    Создал первую ветку `feat-1` (`git branch feat-1`) и переключился на нее (`git checkout feat-1`).
    Внес изменения в проект, отследил их (`git add .`) и закоммитил (`git commit -m "..."`).
    Вернулся в `main`, создал вторую ветку `feat-2` и аналогично зафиксировал в ней изменения.
3. **Объединение фичей:**
    Создал общую ветку `dev` для сбора функционала из обоих направлений.
    Выполнил слияние первой ветки (`git merge feat-1`).
    Выполнил слияние второй ветки (`git merge feat-2`). На этом этапе возник конфликт слияния (`merge conflict`).
4. **Разрешение конфликта и завершение:**
    Вручную разобрал конфликт в файле `README.md`, выбрав актуальный код и удалив метки конфликта.
    Зафиксировал результат разрешения конфликта (`git add .` и `git commit`).
    Создал ветку `release`, после чего перенес итоговый результат в основную ветку `main` (`git merge release`).
